How it works

🐕

2
✏️

🔧 Install in 60 Seconds

No Chrome Store. No Waiting. Completely Free.

PET installs directly from GitHub. No $5 fee, no approval wait.

1
Download the extension ZIP

Click the download button → save pet-extension.zip anywhere on your computer.

2
Unzip the file

Extract the ZIP. You'll get a dist/ folder that's the extension.

3
Open Chrome Extensions

Go to chrome://extensions in your browser and enable Developer Mode (top-right toggle).

4
Load the dist/ folder

Click "Load unpacked" and select the dist/ folder you extracted. Done — your pet appears! 🐾
